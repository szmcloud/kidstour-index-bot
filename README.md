# KidsTourIndexBot について

KidsTourIndexBot は、子ども向けのツアー・キャンプ・親子ワーケーションの募集情報を横断して探せる情報サイト（準備中）のために、公開されている募集ページを確認するプログラムです。

## 何をしているか
- 公開ページの内容（日程・対象・料金・締切・主催者など）を確認し、公式ページへのリンク付きで紹介する目的で利用します。
- ページ本文や写真を、そのまま転載して公開することはしません。

## アクセスのルール
- 各サイトの robots.txt に従い、禁止されているページには一切アクセスしません。
- 同一サイトへのアクセス間隔は5秒以上、同じページへの取得は週に2回までです。
- 取得できなかった場合も、短時間に繰り返しアクセスしません。

## 取得の停止をご希望の場合
次の方法でお知らせください。確認後、速やかに対象から外します。
- このリポジトリの Issues（https://github.com/szmcloud/kidstour-index-bot/issues）に、対象のURLと「取得停止希望」とご記入ください。
